موقع ذكريات عيد الميلاد — نسخة بسيطة قابلة للنشر

1) افتحي index.html لمعاينة الكود (للتعديل استخدمي أي محرر نصوص/كود).
2) بدّلي النصوص العامة باسم الشخص وتفاصيل ذكرياتكم.
3) لإضافة صور فعلية، ضعي الصور داخل مجلد الصور في نفس المشروع وعدّلي مربعات الصور في index.html إلى:
   <div class="photo"><img src="images/photo1.jpg" alt="ذكرى جميلة"></div>
   وأنشئي مجلد images وضعي فيه photo1.jpg وغيرها.
4) انشري المجلد أو ملف ZIP عبر Vercel Drop إن كان متاحًا لحسابك، أو ارفعيه إلى مستودع GitHub ثم استورديه من Vercel.
ملاحظة: هذا قالب تجريبي عام؛ لا يحتوي على صورك الشخصية ولا ينشئ رابطًا منشورًا تلقائيًا.
